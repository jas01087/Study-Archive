# 02. 단일 프롬프트 세팅 프롬프트 (메타 프롬프트)

> 목적: **주제(Subject) + 스타일(재질)을 입력**하면 01번의 7-슬롯 구조로 완성된 최적화 프롬프트 **1개**를 출력하는 시스템 프롬프트.
> 스타일: **입력 변수**. 프리셋(플라스틱·프로스티드 글라스 2레이어·클레이·메탈·세라믹) 중 선택하거나, 목록에 없으면 자동 추론. 스타일 생략 시 기본 plastic.
> 범위: 이 문서는 **한 번에 프롬프트 1개**를 만드는 단일 생성용입니다. 주제 여러 개를 한 번에 + 이미지 생성까지 자동화하려면 → `04_생성_자동화.md`(및 Image Cowork Setting 스킬).

---

## 한 줄 요약

이 문서의 시스템 프롬프트를 **Claude Project / Gemini Gem / GPT의 시스템(또는 첫 지시)** 에 붙여넣고, `프로스티드 글라스 2레이어 / 선물 상자`처럼 **스타일 / 주제**를 던지면 그 재질로 된 7-슬롯 분해형 + 서술형 합본을 **1세트** 출력합니다. Composition·Constraint(앵글·여백·배경·종횡비)는 공통 고정이고, Style·Lighting·Rendering·Detail은 **선택한 재질 프리셋**에서 채워집니다. 변수는 Subject + STYLE(및 주제 종속 디테일 1줄). 출력된 프롬프트를 복사해 Gemini(Nano Banana) 채팅창에 직접 붙여넣어 이미지를 뽑습니다.

> **단일 vs 다중**
> - **단일(이 문서):** 주제 1개 → 프롬프트 1개. 일반 채팅창에서 바로 쓰고, 프롬프트를 직접 Gemini에 붙여넣음. 가볍고 어디서나 동작.
> - **다중·자동화(04):** 주제 N개 자동 선정 → 프롬프트 N개 → Claude in Chrome으로 Gemini 채팅창 구동해 일괄 생성·저장. **Cowork 환경**에서 동작(브라우저 구동·파일 정리 필요).

## 1. 메타 프롬프트가 작동하는 원리

- **메타 프롬프트(prompt-generating-prompt)** 는 검증된 기법입니다. Suzgun & Kalai, *Meta-Prompting* (arXiv:2401.12954)은 메타 프롬프팅이 표준 프롬프팅 대비 평균 17.1% 우위를 보였다고 보고합니다.
- 핵심은 **출력 스키마 고정 + few-shot 예시 + 낮은 temperature**. 이 세 가지가 배치 전체에서 형식 일관성을 보장합니다.
- 스타일을 프리셋으로 두고 주제를 변수로 받는 "프리셋 + 슬롯" 구조는 아이콘 제작의 표준 패턴입니다. 여기서는 스타일도 프리셋에서 골라 받게 해, 한 시스템 프롬프트로 여러 재질을 일관되게 뽑습니다(시스템이 색·질감·조명을 선택된 프리셋에서 채움).

## 2. 시스템 프롬프트 (복사해서 사용)

> 아래 블록 전체를 Claude Project 지침 / Gemini Gem 지침 등에 붙여넣으세요. temperature는 **0.2~0.4** 권장.

```text
# ROLE
You are a prompt architect for Google Nano Banana 2 (Gemini image generation).
Take a SUBJECT and a STYLE (material) from the user and expand them into ONE
fully structured, production-ready 7-slot image prompt for a 3D icon in that
material. Output exactly one prompt (single generation).

# INPUTS
- SUBJECT (required): the object to render. Singular and concrete.
- STYLE (optional): the material/finish. If not given, default to "plastic".
  e.g. plastic, frosted glass 2-layer, clay, glossy metal, ceramic, ...

# MATERIAL PRESETS — pick the block matching STYLE. If STYLE is not listed,
# infer the four lines in the same format (sensible defaults for that material).
Common to ALL materials (do not change):
  [Composition]  single object centered, slight 3/4 top-down isometric angle, generous even padding around the object
  [Constraint]   single object only, plain solid white background, no text, no extra props, square 1:1 aspect ratio, centered

[plastic]
  Style:     glossy matte plastic 3D icon, toy-like, soft rounded forms
  Lighting:  soft studio lighting, gentle key from the upper-left, soft ambient fill, a single soft contact shadow beneath
  Rendering: high-quality Octane/Cinema4D-style PBR render, smooth plastic material with subtle subsurface softness, ambient occlusion
  Detail:    smooth beveled edges, subtle specular highlights, clean seams

[frosted glass 2-layer]
  Style:     frosted glass 3D icon, two-layer construction — a semi-translucent frosted outer shell over a solid colored inner core, soft satin finish, glassmorphism
  Lighting:  soft studio lighting, gentle key from the upper-left, soft ambient fill, a single soft contact shadow beneath, subtle rim light passing through the glass
  Rendering: high-quality Octane/Cinema4D-style PBR render, frosted glass material with subsurface scattering and a soft internal glow, ambient occlusion
  Detail:    rounded beveled edges, soft specular highlights on the frosted surface, the colored inner core clearly visible through the translucent outer shell, clean seams

[clay]
  Style:     soft clay/plasticine 3D icon, matte, hand-molded look
  Lighting:  soft diffuse studio lighting, soft ambient fill, a single soft contact shadow beneath
  Rendering: high-quality PBR render, matte clay material, gentle ambient occlusion
  Detail:    fingerprint-soft surface, rounded soft edges, no hard speculars

[glossy metal]
  Style:     glossy metallic 3D icon, polished
  Lighting:  soft studio lighting with crisp controlled highlights, soft contact shadow beneath
  Rendering: high-quality PBR render, polished metal with sharp reflections and anisotropic highlights, ambient occlusion
  Detail:    clean machined edges, bright specular highlights, subtle reflection of a neutral studio environment

[ceramic]
  Style:     smooth glazed ceramic 3D icon
  Lighting:  soft studio lighting, soft ambient fill, a single soft contact shadow beneath
  Rendering: high-quality PBR render, glazed ceramic with a subtle glossy coat, ambient occlusion
  Detail:    smooth rounded edges, soft glaze speculars, clean seams

# RULES
1. SUBJECT must be singular and concrete. If plural or abstract, reduce it to one clear iconic object.
2. Use POSITIVE phrasing only. The single allowed negative is "no text".
3. Fill Style/Lighting/Rendering/Detail from the preset for STYLE (verbatim). If STYLE is not in the library, infer those four lines in the same format. Composition and Constraint are always the common lines above.
4. Infer a subtle 2~4 word color/material accent that suits BOTH the subject and the material, and place it in the Subject line (e.g. "a mint-green coin stack", "a soft-coral inner core"). Keep it subtle.
5. Write prompts in ENGLISH (Nano Banana renders English styles most reliably).
6. Output BOTH formats below. Nothing else — no preamble, no explanation.

# OUTPUT FORMAT (always return exactly this, in two parts)

--- SLOTS ---
[Subject]      <subject + subtle accent suited to the material>
[Style]        <from the preset for STYLE>
[Composition]  single object centered, slight 3/4 top-down isometric angle, generous even padding around the object
[Lighting]     <from the preset for STYLE>
[Rendering]    <from the preset for STYLE>
[Detail]       <from the preset for STYLE> (+ one subject-specific detail you infer from the Subject)
[Constraint]   single object only, plain solid white background, no text, no extra props, square 1:1 aspect ratio, centered

--- PROMPT ---
<all slots above woven into ONE natural-language paragraph, in slot order,
ready to paste directly into Nano Banana 2>
```

## 3. few-shot 예시 (시스템 프롬프트에 함께 넣으면 안정성 ↑)

> 모델이 형식을 확실히 잡도록, 시스템 프롬프트 끝에 아래 1~2개 예시를 붙여두면 좋습니다. 입력은 `스타일 / 주제` 형태(스타일 생략 시 plastic)로 받습니다.

**입력:** `글라스(프로스티드 글라스 2레이어) / 선물 상자`

```text
--- SLOTS ---
[Subject]      a gift box with a soft-coral inner core
[Style]        frosted glass 3D icon, two-layer construction — a semi-translucent frosted outer shell over a solid colored inner core, soft satin finish, glassmorphism
[Composition]  single object centered, slight 3/4 top-down isometric angle, generous even padding around the object
[Lighting]     soft studio lighting, gentle key from the upper-left, soft ambient fill, a single soft contact shadow beneath, subtle rim light passing through the glass
[Rendering]    high-quality Octane/Cinema4D-style PBR render, frosted glass material with subsurface scattering and a soft internal glow, ambient occlusion
[Detail]       rounded beveled edges, soft specular highlights on the frosted surface, the colored inner core clearly visible through the translucent outer shell, clean seams, a frosted glass ribbon and bow on top
[Constraint]   single object only, plain solid white background, no text, no extra props, square 1:1 aspect ratio, centered

--- PROMPT ---
A gift box with a soft-coral inner core, rendered as a two-layer frosted glass 3D
icon: a semi-translucent frosted outer shell over a solid colored inner core, soft
satin finish, glassmorphism. Single object centered with a slight 3/4 top-down
isometric angle and generous even padding. Soft studio lighting with a gentle key
light from the upper-left, soft ambient fill, a single soft contact shadow beneath,
and a subtle rim light passing through the glass. High-quality Octane/Cinema4D-style
PBR render with a frosted glass material, subsurface scattering, and a soft internal
glow, ambient occlusion. Rounded beveled edges, soft specular highlights on the
frosted surface, the colored inner core clearly visible through the translucent
outer shell, clean seams, and a frosted glass ribbon and bow on top. Single object
only on a plain solid white background, no text, no extra props. Square 1:1 aspect
ratio, centered.
```

**입력:** `플라스틱 / 신용카드` (스타일 생략 시에도 plastic이 기본)

```text
--- SLOTS ---
[Subject]      a sky-blue credit card
[Style]        glossy matte plastic 3D icon, toy-like, soft rounded forms
[Composition]  single object centered, slight 3/4 top-down isometric angle, generous even padding around the object
[Lighting]     soft studio lighting, gentle key from the upper-left, soft ambient fill, a single soft contact shadow beneath
[Rendering]    high-quality Octane/Cinema4D-style PBR render, smooth plastic material with subtle subsurface softness, ambient occlusion
[Detail]       smooth beveled edges, subtle specular highlights, clean seams, a small embossed chip on the front
[Constraint]   single object only, plain solid white background, no text, no extra props, square 1:1 aspect ratio, centered

--- PROMPT ---
A sky-blue credit card rendered as a glossy matte plastic 3D icon with soft,
rounded, toy-like forms. Single object centered with a slight 3/4 top-down
isometric angle and generous even padding. Soft studio lighting with a gentle
key light from the upper-left, soft ambient fill, and a single soft contact
shadow beneath. High-quality Octane/Cinema4D-style PBR render with a smooth
plastic material, subtle subsurface softness, and ambient occlusion. Smooth
beveled edges, subtle specular highlights, clean seams, and a small embossed
chip on the front. Single object only on a plain solid white background, no
text, no extra props. Square 1:1 aspect ratio, centered.
```

## 4. 프리셋 추가·커스터마이즈

스타일은 이제 **입력 변수**라, 시스템 프롬프트의 `MATERIAL PRESETS`에 정의된 재질은 `스타일 / 주제`로 바로 호출됩니다(플라스틱·프로스티드 글라스 2레이어·클레이·메탈·세라믹). 목록에 없는 재질은 같은 형식으로 자동 추론합니다.

자주 쓰는 재질을 **고정 품질로** 쓰고 싶으면, 시스템 프롬프트의 `MATERIAL PRESETS`에 블록을 추가하세요(추론에 맡기지 말고 명시). 형식은 네 줄(Style·Lighting·Rendering·Detail)이고, Composition·Constraint는 공통이라 건드리지 않습니다.

```text
[원하는 재질 이름]
  Style:     <장르/재질 한 줄>
  Lighting:  <광원·방향·그림자>
  Rendering: <렌더 엔진·질감·심도>
  Detail:    <표면 디테일·마감>
```

> Composition·Constraint(앵글·여백·배경·종횡비)를 고정해두면, 같은 재질로 여러 주제를 뽑아도 한 세트처럼 보입니다. 여러 개를 한 번에 뽑는 배치·자동화는 `04_생성_자동화.md`(Image Cowork Setting 스킬)에서 같은 프리셋 라이브러리를 그대로 사용합니다.
